EASYLOOP — VERSIONE 1 (GRATUITA)

PROVA IMMEDIATA SU COMPUTER:
Apri index.html con un browser moderno.

INSTALLAZIONE SU IPHONE (PWA):
1. Crea un repository pubblico GitHub, ad esempio easyloop.
2. Carica i 4 file della cartella easyloop nella radice del repository.
3. Vai su Settings > Pages > Build and deployment > Deploy from a branch, branch main, folder /(root), Save.
4. Attendi la pubblicazione e apri il link HTTPS indicato da GitHub Pages in Safari su iPhone.
5. Tocca Condividi > Aggiungi alla schermata Home > Aggiungi.
6. Apri EasyLoop dalla schermata Home.

Il sito GitHub Pages è pubblico: NON caricare dati personali o PDF protetti nel repository. I dati inseriti nell'app restano localmente sul tuo dispositivo. Non è prevista sincronizzazione tra dispositivi.

FUNZIONI: progetti multipli, istruzioni personalizzabili per ferro, aumento/diminuzione ogni N ferri, conteggio maglie atteso, verifica manuale, errori con note, storico, timer, materiali/costi, link tutorial, allegati PDF locali, backup JSON.

IMPORTANTE: il progetto Sophie Scarf incluso è un ESEMPIO PERSONALIZZATO, non una riproduzione verificata del tutorial o del pattern originale. Controlla tutte le istruzioni prima di lavorare. Il backup JSON NON include gli allegati PDF.

PRIVACY: i dati sono conservati nel browser tramite localStorage e IndexedDB. Se cancelli i dati del sito potresti perderli. Esporta regolarmente un backup JSON e conserva i PDF originali.
